How it works

  1. Build one file. HTML, CSS and JavaScript all inside a single page.
  2. Test run it. The game boots in a sealed arcade cabinet so you can check it plays.
  3. Submit. It lands in the queue below as pending.
  4. Levi reviews. Approved games take the next open slot on the wall.
